## 3. 確認事項・バグの疑い

- 疑い 1：InputSection の項目名の表は displayName・valuesText・activityLevel（camelCase）で引くが、サーバーの詳細 API は generation_events.input_attributes をそのまま返し、その中身は promptBuilder の UsedAttributes（display_name・values_text・activity_level、snake_case）である。そのため P208 では表示名・価値観・活動頻度が英語の項目名のまま出る（TC-UT_P208-008）。DEV-12 は camelCase の値で書かれていて、この食い違いを見ていない。
- 疑い 2：画面基本設計書 H08（行動の候補）は「decided_by が llm のとき」だけ出す項目だが、InputSection は gate でも見出しを出し「なし」と表示する（TC-UT_P208-009）。記憶・参照した投稿は llm のときだけで、設計どおり。
- 確認事項 3：P208 の様式①の文言は、画面基本設計書が「生成ログを取得できませんでした」（後半なし）、P207 が「…時間をおいて再度お試しください」付きで、画面ごとに違う。実装はどちらも設計どおり。
