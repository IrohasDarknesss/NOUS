## 3. 確認事項・バグの疑い

- 疑い 1：P202 6章の 409 NO_AGENTS は「P203 へのリンクを添える」だが、様式②は文言だけでリンクがない（ErrorBanner は文字列だけを受ける）。TC-UT_P202-008 はリンクを期待するので、実施では NG になる見込み
- 疑い 2：P202 E01 の「様式①: 500 は「状態を取得できませんでした」」が実装されていない。世界の状態の取得が失敗すると「世界の状態を読み込み中…」のままになり、3 回続けて失敗したときに様式②「最新の状態を取得できていません」が出るだけ。TC-UT_P202-013 は仕様どおり様式①を期待するので、実施では NG になる見込み
- 確認事項 1：P202 H17 は「一致するまで確定を押せない」だが、実装は押してから「世界の名前が一致しません」を出す（FE 詳細設計 submitReset に合わせた。NOUS-69 で Takaya Ishikawa さんが判断を書き、再鑑で完了）。どちらを正とするかは画面設計書の更新で揃えるのがよい。TC-NOUS69_DEV-14 は実装の形で確かめている
