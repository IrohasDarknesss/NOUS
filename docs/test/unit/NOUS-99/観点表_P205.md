- 疑い 1：computeEstimate の周期の下限が、サーバーの estimateDaily と食い違う。FE 詳細設計 4章は「サーバーの estimateDaily と同じ式」としているが、サーバーは下限を 15 分（SETTINGS_RANGES の下限）より小さくせず、1巡の Neurons が 0 のときも 15 にする（NOUS-58 の決めたこと 5）。画面は ceil の値をそのまま出し（例：活動量 10% で 2 分）、1巡の Neurons が 0 なら 0 を出す。TC-UT_P205-001・002 はサーバーと同じ 15 を期待するので、実施では NG になる見込み。TC-NOUS69_DEV-19 は 0 を期待していて、仕様と合わない
- 確認事項 1：P205 H01 は直近 50 件に満たないとき「実測なし（見積もり 16.4）」と出すが、実装は平均の値（小数 1 桁）を出すだけ。GET /admin/api/settings は件数を返さず、サーバーは 20 件未満で 16.4 を返す（world.md 2章）。画面で見分けられないため、API に件数か実測かどうかを足すか、画面設計書の記載を直すかの確認
- 確認事項 2：設定の取得が 404 のとき何も出さない（TC-UT_P205-019）は設計書に記載がなく、実装の値を期待結果にした
