## 3. 確認事項・バグの疑い

- 疑い 1：画面基本設計書 P201 の L09「あと N 回失敗すると 15 分ロックされます」（失敗が 3 回以上のとき、N=5−失敗回数）が実装されていない。LoginPage に失敗の回数を数える処理と文言がない。TC-UT_P201-013 は仕様どおり 3 回目の失敗の後にこの文言を期待するので、実施では NG になる見込み。ログインの API は残りの回数を返さないため、画面で数えるか API で返すかの決めも要る
- 確認事項 1：submitLogin の送信中の再送の防止（LoginPage.tsx:104 の if (submitting) return）は、送信中は入力欄とボタンを disabled にするため画面の操作では通らない。TC-UT_P201-004 で、送信中に押せないことを確かめている
- 確認事項 2：submitLogin で ApiError・NetworkError 以外の例外を様式①にする分岐（LoginPage.tsx:153）は、signIn（adminFetch）がこの2つしか投げないため通らない。B22-F（ApiError でも NetworkError でもない）はこの分岐のことで、理由は同じ
