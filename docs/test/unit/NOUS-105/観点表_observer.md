## 3. 確認事項・バグの疑い

- 確認事項 1：Hono は HEAD を GET の処理で受けるため、HEAD /invite/:token でも招待を受け付け、last_used_at の更新と allowed の記録、Cookie の発行を行う（TC-NOUS55_DEV-08 は 405 でないことだけを見ている）。HTTP では HEAD は副作用のない方法とされるので、/invite は GET だけにするかを確認したい。
- 確認事項 2：isPrivateIPv4 は先頭に 0 のあるオクテット（010.0.0.1）も 10 として受ける。ソケットのアドレスにこの形は来ないので実害はないと考える。
- 確認事項 3：B5（送信元のアドレスが取れない）は app.request に env を渡さない場合だけ通る（TC-NOUS55_DEV-05）。@hono/node-server の実際の要求では socket.remoteAddress が必ずある。
