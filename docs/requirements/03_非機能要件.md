## 6. 非機能要件（非機能要求グレード2018 準拠）

> 想定モデルシステム：**社会的影響が殆どないシステム**
> 根拠：MVP の利用者は開発者本人と招待観察者に限られ（PRE-002）、公開範囲は開発者本人と招待観察者に限り、閲覧は同じネットワークの中からに限る（Q-001・Q-605 の回答）。外部への送信を持たない閉域のシミュレーションであり（CON-003）、停止しても第三者の業務に影響しない。以上の確定した前提から、このモデルを選ぶ。一般公開を検討するときにモデルを見直す。

### 6.0 本章の記述ルール

- **優先度**：要求定義書 05_非機能要求は優先度の列を持たない。導入期が MVP のものを Must、V1.1 のものを Should とした。当初は推定として Q-316 で確認したが、2026-10-19 にチームの決定（admin の委任による）で確定した。
- **状態**：01・02 章と同じく、合意済 / 提案（未合意）/ 要確認 を用いる。数値が決まっていないために基準を書けないものは「要確認」とする。
- **未確認**：要求定義書に記載がなく、推定の根拠もないものは「未確認」と書き、確認事項を挙げる。空欄にはしない。
- **ID の拡張**：requirements-definition の 6大項目の略号に加え、6.7 の準非機能に U、6.8 の LLM 固有の要件に L を用いる。6大項目のいずれにも収まらない要件を、無理に寄せずに扱うためである。
